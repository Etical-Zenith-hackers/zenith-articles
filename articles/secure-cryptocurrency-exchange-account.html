How to Secure a Cryptocurrency Exchange Account

An exchange account can be a target for phishing, password reuse, SIM swaps, and compromised devices. A few preventive controls can reduce risk, though no setup eliminates it entirely.

Use a unique password

Create a long, unique password that is not used on email or any other service. A reputable password manager can help generate and store it securely.

Enable strong multifactor authentication

Use a phishing-resistant method or authenticator app where supported. Store backup codes securely offline. SMS may be better than no second factor, but it can be vulnerable to SIM-swap attacks.

Review withdrawal and API settings

Enable withdrawal allowlists, address confirmation, and time delays if the platform offers them. Remove API keys you do not recognize and limit permissions for any keys you keep.

Secure the email account behind it

Protect the associated email account with a unique password and strong MFA. Review forwarding rules, recovery options, active sessions, and unfamiliar devices.

Recognize phishing

Navigate using a saved bookmark or official app. Be suspicious of urgent messages, sponsored lookalike websites, fake support accounts, and requests to reveal one-time codes or seed phrases.

Prepare an incident plan

Know the exchange's official support path, keep transaction records, and document account identifiers securely. If compromise is suspected, contact the platform promptly through verified channels.
