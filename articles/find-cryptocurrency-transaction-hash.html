How to Find a Cryptocurrency Transaction Hash

A transaction hash, also called a TXID or transaction ID, is a unique identifier for an on-chain transaction. It is often the most useful starting point when asking a wallet provider or exchange about a transfer.

Look in wallet activity

Open the wallet's transaction history, select the relevant transfer, and look for transaction details, explorer link, TXID, or transaction hash. Labels differ by wallet and network.

Look in an exchange withdrawal or deposit record

Sign in through the official exchange website or app. Open withdrawal or deposit history and select the relevant record. Some platforms show the hash only after the transaction has been broadcast.

Verify the network

Check the asset and network carefully. Similar token names can exist on different chains, and an explorer for the wrong chain may not show the transaction.

Check status with an explorer

Use a reputable explorer for the relevant chain and paste only the public transaction hash. Review confirmation status, timestamp, sender and recipient addresses, and token details where available.

Share information safely

A TXID is generally public transaction metadata, but avoid posting unrelated personal details. Never share a wallet seed phrase, private key, password, or one-time code to prove a transaction.

If the hash is missing

Contact the sending service's official support and ask for the transaction reference. If the transfer was an internal ledger movement, it may not have an on-chain TXID.
